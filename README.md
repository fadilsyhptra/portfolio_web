## 🛠️ Key Features (Modul Unggulan)

* **Tactical HUD Design:** Skema warna gelap (*deep space*) dikombinasikan dengan aksen neon kembar (*Neon Cyan* & *Neon Purple*) untuk kenyamanan mata (*dark mode native*).
* **Skills Core Matrix:** Penggantian indikator persentase konvensional menjadi *Cyberpunk Grading System* berstatus taktis (`[ OPTIMIZED ]`, `[ ADVANCED ]`, `[ STABLE ]`) yang dilengkapi dengan animasi pemuatan data linear.
* **Tech Dossier Layout (Education Timeline):** Garis konektor vertikal bergaya sirkuit komputer yang secara otomatis beradaptasi menjadi susunan panel bertumpuk saat diakses via ponsel pintar.
* **Sleek Cyber Links:** Integrasi tombol kontak sosial media berlogo resmi (Instagram, LinkedIn, Email) dengan efek pendaran cahaya (*glow animation*) yang responsif.
* **Mobile-First Fluid Layout:** Optimasi penuh di berbagai resolusi layar (Desktop, Tablet, hingga HP super sempit ukuran 480px) untuk mencegah terjadinya *layout overflow*.
